03 / BUILD SOMETHING USEFUL

写好扩展，把入口交给这里。

从一份收录资料开始。源码与发行包，仍然留在你自己的仓库。

完整投稿指南 ↗

三个步骤，加入目录。

  1. 发布完整插件

    提供 GitHub Release 或预构建 npm 包。请勿只提交源码或需要安装脚本的交付物。

  2. 补齐收录资料与图标

    在 entries/<manifest-id>.json 中描述插件，图标放在 assets/。ID 要与包内清单一致。

  3. 校验、构建，提交 PR

    CI 核对变动条目的实际发行材料。资料和图标来自同一份目录，不维护“最新版本”镜像。

LOCAL / Varin-plugins
npm ci --ignore-scripts
