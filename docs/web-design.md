# 插件市场网页

## 本轮设计依据

本次重新拆解用户提供的 Varin Extensions 前端原型，以最终组件源码及最终桌面/详情参考图为准，而不是包内较早的居中大标题、双列卡片版本。视觉 CSS 直接适配原型的 tokens、scene、marketplace、anatomy、layers 与六个微动效组件，保留静态网页架构，没有导入 React、原型依赖、媒体缓存或模拟目录。

原型 ZIP SHA-256：`f8ccbf1afecd828e9548168de4c28652cfd166c4bc1785a1333177b0912ebe02`。最终桌面参考图为 `media_1794048002594_bdc641ab.jpg`，详情参考图为 `media_1794048004148_3a23df77.jpg`。这些名称只用于区分设计版本，不是当前实现截图。

### 保留的视觉和交互结构

- 暖纸色 `#fcfbf9`、卡片 `#fffefd`、石墨深色主题、细线边界、纸面纹理、系统中英文字体与等宽字段。纹理移至本地 SVG，保持同源 CSP。
- 60px 导航，1200px 容器及 28px 桌面内边距；42px 左对齐主标题与小副标题，紧凑首屏，无上一版大型营销标题和额外首屏按钮。
- 96px CSS 3D 立方体、58°/45° 相机、1800px 透视、每面独立的 4×4 格子和双路径品牌标记。Canvas 地面使用相同投影，按源原型保留固定地面及立方体的轻微指针反馈。
- 低对比分类/来源/排序工具栏；桌面三列、20px 间距及20px 圆角卡片；独立图标、类别标签、标题、等宽 ID、双行介绍与底部安装条。
- 980px 原生 dialog，黏性标题、暖灰安装条、两栏简介、左侧字段解剖与右侧暗色代码面板。字段悬停、聚焦、点击会联动高亮，代码标签页支持方向键/Home/End。
- 下半页三层分工、字段说明、六张微动效卡片，以及两栏脚手架和资料预检区；采用紧凑小标题而非大型重复章节。

### 有意的生产适配

- 目录唯一来源是构建生成的 `catalog/v1.json`，目前真实条目为 **0**。正式页面呈现空状态，不用原型的 24 个演示插件填充卡片。三列卡片和详情由仅存在于浏览器测试中的注入资料覆盖。
- “官方/社区”改为真实可验证的 GitHub Release/npm 来源；不声称官方认证、精选、安装次数、评分、最新版本或已安装状态。排序使用实际存在的名称/作者。
- 分类保留原型的五个发现入口，数字来自实际资料；其他作者提供的分类动态补充。不据此推断权限、运行层或支持平台。
- 安装条复制实际 `varin://extensions/install` 链接，包含原始来源和扩展 ID；详情展示收录 JSON，不把它冒充完整扩展 manifest。没有虚构 `varin extension add` 命令。
- 公开目录、作者发行、应用 Host 的三层文案来自当前仓库的实际分工。浏览网页不访问作者发行、不执行插件代码。
- 脚手架使用真实 `@varin/extension-cli` 的 7 种模板：surface/shell/editor/view/language/debug/test，包含必填 `--id`、`--name`。名字使用 `--name=` 和 POSIX shell 引号，`&&` 链保证初始化失败后不继续进入既有项目。页面只生成文本。
- 小字号正文使用更深的 `--sage-text: #626e69`，装饰保留原 sage，避免继承参考稿的小字低对比度问题。移动端淡化装饰、调整字号；1080px 及以下收起较长的真实导航标签。

## 访问性、真实性与安全

搜索支持 `/` 快捷键和可分享筛选 URL。原生 dialog 用于焦点约束、Esc/关闭/背景关闭和焦点恢复；复制失败时显示可选中的真实链接。移动导航有展开状态和 Esc 关闭。减少动态效果设置会停止 CSS 动画和 canvas 动画；画面离屏或页面隐藏时暂停 canvas。

主题偏好只保存在浏览器本地，存储不可用时仍可切换，页脚可恢复跟随系统。目录文本经 DOM `textContent` 渲染，来源与资源路径先做校验。CSP 不放宽，不引入 CDN、远端字体、跟踪器或第三方图片请求。

开发者预检只检查收录 JSON 的基础结构，不上传输入，不验证发行可用性、SemVer 范围、图标文件或代码安全，不替代仓库和发行核验。详情中的“在预检中检查”传入实际条目，并恢复 `entries/*.json` 所需的图标路径。
