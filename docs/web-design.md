# 插件市场网页

以提供的 Varin Extensions 前端原型为视觉参考，重新实现为仓库现有的静态网页：暖白/石墨配色、细线边界、等距网格与品牌立方体、目录卡片、详情弹窗及开发者工作区。品牌标记沿用原型中注明来自 Varin 自身的几何路径；没有导入原型的依赖、媒体缓存或模拟目录数据。

## 真实数据边界

- 目录唯一来源为构建生成的 `catalog/v1.json`。目前正式目录为空，空状态明确显示事实，并提供投稿与直接安装说明。
- 来源标签区分 GitHub Release 与 npm，不推断“官方”“精选”或审计身份。
- 不显示没有来源的安装次数、星标、评分、最新版本、权限数量、运行层、已启用状态或安装开关。
- 插件详情展示收录资料及发行选择器。具体版本、权限及兼容性在用户自己的 Host 中解析和审阅。
- 开发者预检是收录 JSON 的基础结构检查，不是假装运行 `varin-extension check`，不会请求或执行第三方插件代码。

## 交互与访问性

搜索支持 `/` 快捷键；表单、源码展开和所有操作可使用键盘。原生 dialog 提供焦点约束、Esc/关闭按钮/背景关闭以及关闭后的焦点恢复。复制失败时呈现可手动复制的链接。主题偏好仅保存在浏览器本地，存储不可用时仍可切换；默认跟随系统，并尊重减少动态效果设置。

页面沿用同源 CSP，不引入 CDN、远端字体、跟踪器或第三方图像请求。目录中的文本用 DOM textContent 渲染，来源与资源路径先做基础校验。浏览器校验是展示层防御，不替代构建端验证。

## 验证

- `npm test`：目录、发行核验与浏览器纯函数回归。
- `npm run validate` / `npm run check:releases` / `npm run build`：既有资料和发行校验链路。
- `npm run test:site`：真实 Chromium 中的 12 组交互场景，在生产 CSP 下运行，含 320/390/768 px 布局与深色主题。
